# Method

The paper's 48 displayed rows were transcribed into a pinned CSV. The production
checker uses Decimal arithmetic and validates the complete Cartesian ensemble
design. A separately written checker uses integer hundredths of a percentage
point and imports no production module. Both recompute the aggregate from all
rows rather than trusting the paper's prose.

Controls mutate a winning OW-L row and the maximum-lift row; both must make the
contract fail. A third control evaluates the conflated OW-L-only range and must
reject it.
