# Claim 2 limitations

The certificate concerns population pairwise conditionals, exactly as in
Theorem 2. It does not certify finite-sample estimation guarantees, which are
a separate theorem. The independent enumeration is corroboration; the generic
exact-algebra identity and nonnegativity argument provide universal scope.

`N=1` is excluded because Algorithm 2 divides by `N-1`. Accuracies below
`1/K` are outside Section 4's stated scope and are exercised only as a
negative control.
